# AI Business Platform

## Applications
- frontend: Angular Standalone
- backend: NestJS REST API

## Development URLs
- Frontend: http://localhost:4200
- Backend: http://localhost:3000

## Backend setup
Follow [backend/README.md](backend/README.md) to configure PostgreSQL and the
JWT secret, then run `npm install` and `npm run start:dev` from the `backend`
directory.
